# Avance del Tutor IA de hábitos de estudio

Resultados de la Bitácora 1 y la Bitácora 2 del Tutor IA de hábitos de estudio (Inglés L2), grupo 2A0, *Tutoring for Immersion*, Universidad Politécnica de Santa Rosa Jáuregui, septiembre–octubre de 2026.

La página (`index.html`) reúne avances, fricción útil, problemas detectados, trayectorias por alumno y ajustes propuestos para el prompt v5. El video (`tutor-ia-vida-real.mp4`) muestra la vida real detrás del hábito. Los alumnos están anonimizados.
